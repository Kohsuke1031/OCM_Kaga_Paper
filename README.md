This document contains OCM code Markdown files and the data used within them.

catch_trawl_yearly.rds and catch_setnet_yearly.rds are annual landing data, aggregated by major and other species for each fishery type.

simpson_catch.rds represents the species diversity of landing speceis for both fishery type.

catch_trawl_monthly.rds and catch_setnet_monthly.rds are monthly landing data for each fishery type, broken down by species.
